# 🚀 Startup Opportunity Aggregator

A full-stack AI-powered startup opportunity aggregator that scrapes, enriches, and displays startup/job/funding opportunities in real-time.

---

## 📌 Features

- 🔄 Automated scraping with scheduler (node-cron)
- 🤖 AI-powered enrichment (OpenAI API)
- 🧹 Duplicate detection system
- 📊 Admin analytics dashboard
- 🔖 Bookmark system for users
- 📈 Trending opportunities section
- ⚡ Real-time updated dashboard
- 🌐 Multi-source scraping (YC, TechCrunch, etc.)

---
